# TSK-Inspired Public Website Redesign Notes

## Reference Reviewed

- URL: https://tsk.com/
- Reviewed: 2026-08-11

## Reference Characteristics to Adapt (Not Copy)

The reference uses a **high-contrast, conversion-focused marketing structure**: a restrained utility bar, a simple logo-led primary navigation, a full-screen hero with one focused headline and one primary CTA, and strong black/white/red visual rhythm. It uses wide whitespace and avoids dashboard-style card density on the public site.

Its homepage hierarchy is intentionally direct: hero → credibility figures → program categories → story/social proof → a repeat CTA → FAQ → footer. The key adaptation for MyDojo is a premium editorial feel: fewer competing widgets, one page-level conversion path, compact navigation, and generous section spacing.

## Current MyDojo Audit

The current home page already has compatible foundation assets: MyDojo logo files, a dojo training montage, class/program photography, Master Holmes photo, program routes, lead capture gate, and a sticky mobile CTA. Its information density is the main issue: it includes overlapping enrollment cards, program cards, testimonials, founder material, FAQ, a campaign-specific final CTA, a utility bar, and a complex header that compete for attention.

## Redesign Principles

1. Use black, warm white, MyDojo red, and a restrained muted gray palette.
2. Keep a single primary action: **Book a Free Class**; retain the existing lead-capture gate.
3. Simplify the header to logo, key program links, location, call, and CTA.
4. Present programs as a clean two-column or four-column image grid with short supporting copy.
5. Replace campaign-expiry copy with evergreen credibility and locally accurate dojo information.
6. Preserve all existing public routes, lead forms, mobile CTA, and enrollment infrastructure.

## Visual Verification — 2026-08-11

The redesigned homepage now presents a single clean hero, a compact credibility strip, editorial program grid, dojo story, founder feature, location callout, FAQ, and final CTA. The public header is always available rather than appearing only after the hero viewport.

The programs page now uses numbered, editorial program rows with one image, concise copy, a program-detail link, and a separate introductory-class action for each existing offering. Existing program route targets and lead-capture conversion entry points remain intact.
