# Customer Payment Copy Verification

## Customer-facing language

Student and customer checkout, enrollment, event-registration, account, and shop copy now uses neutral **Secure Checkout** and **Secure payment** language. Payment processor names are no longer shown in customer-visible labels, buttons, security notices, redirects, or account payment-method cards.

## Security reassurance retained

The revised copy still clearly tells customers that card data is encrypted and that MyDojo does not store card details. Internal payment integrations remain unchanged; this update only removes their public branding.

## Automated verification

Focused payment-copy, Account, and Pro Shop regression suites pass with 10 tests, and TypeScript is clean.
